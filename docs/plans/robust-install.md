# Robust env-driven install + aligned ports — Plan

## 1. Introduction

Make `install.sh` the single, foolproof way to install/restart KDence, with **all ports driven
by an env file**. Canonical defaults become **5785** (API/dashboard) and **5786** (browser
tab-ingest). The installer reads `.env`, generates the systemd user units from *tested* Python
(no fragile `sed`), aligns the browser extension to the ingest port, and (re)starts everything —
so "restart the server" is just re-running `./install.sh`.

Motivating bug: the extension hardcoded port `8766` while the installed collector's ingest ran
on a user-chosen port (`5786`), and `install.sh` *silently auto-bumped* busy ports — so tab
reports went nowhere and no site data was ever recorded. The fix removes the silent divergence
and makes the port a single env-driven value shared by the collector and the extension.

## 2. Gaps & Unanswered Questions

- **Canonical ports.** *Decided (user):* 5785 API, 5786 ingest are the defaults and the "only"
  ports we standardize on; the user changes them in `.env`.
- **Env var names.** *Assumption:* standardize on the `KDENCE_*` names already in `.env.example`
  (`KDENCE_API_PORT`, `KDENCE_INGEST_PORT`, `KDENCE_API_HOST`, `KDENCE_IDLE_THRESHOLD_SECONDS`,
  `KDENCE_CAPTURE_TITLES`, `KDENCE_DB_PATH`). `install.sh` sources `.env` and reads these.
- **Port conflicts.** *Decided (user):* **no silent auto-bump.** If a chosen port is held by a
  *foreign* process, fail with a clear message telling the user to change `.env`. A port held by
  our own service being restarted is fine.
- **Extension port.** The extension can't read a server env file, so `install.sh` writes the
  ingest port into the extension (both builds) at install time; the committed default is 5786,
  so the common case needs no change. The user reloads the extension after install.
- **No `sed` on unit ExecStart.** The `service install` CLI takes the ports directly and the
  pure `units.py` renderer emits them, so unit content stays generated + unit-tested.

## 3. Steps

### Step 1 — Canonical ports + env contract + ports through the generator
- **Locations:** `api/server.py` (`_DEFAULT_PORT=5785`), `browser/ingest.py`
  (`DEFAULT_INGEST_PORT=5786`), `service/units.py` (`DEFAULT_PORT=5785`, add `ingest_port` to
  `UnitContext`, collector `ExecStart` emits `--ingest-port`), `service/__main__.py` (`install`
  gains `--api-port`/`--ingest-port`/`--threshold`/`--store`/`--titles`), both
  `browser-extension/*/tab-reporter.js` (endpoint `5786`), `tests/browser/test_extension_manifests.py`
  (assert `5786`; the manifest host permission also becomes `127.0.0.1:5786`),
  both `browser-extension/*/manifest.json` (host permission → `:5786`), `.env.example` (canonical
  vars + 5785/5786). Tests: extend `tests/service/test_units.py` for the ingest port.
- **Test:** unit renderer emits `--ingest-port 5786`; `service install --ingest-port N` bakes N;
  manifest guard asserts loopback `:5786` only. Full headless sweep green.
- **Action:** commit: `Robust Install (1/3) Complete: canonical 5785/5786 ports + ports through the unit generator`.

### Step 2 — Robust, env-driven `install.sh`
- **Locations:** `install.sh` (rewrite), `.env.example` (final).
- **Changes:** source `.env`; resolve `KDENCE_*` with 5785/5786 defaults; **drop** `find_free_port`
  auto-bump — instead `die` on a foreign conflict with a fix hint; generate units via
  `kdence.service install --api-port … --ingest-port … --threshold … [--titles] [--store …]`
  (no `sed`); patch the extension's ingest port in both builds; `daemon-reload` + `enable --now`
  + `restart`; poll `http://127.0.0.1:$API/api/health` and `die` if not up; print a summary
  (dashboard URL, ingest port, store) + a **reload-the-extension** reminder.
- **Test:** run `./install.sh`; both services active on 5785/5786, `/api/health` OK, units on
  disk match the running ports, extension endpoint = 5786.
- **Action:** commit: `Robust Install (2/3) Complete: env-driven, no-silent-bump install.sh that aligns the extension`.

### Step 3 — Docs + regression
- **Locations:** `README.md`, `docs/workflow.md`, `docs/documentation.md`, `docs/structure.md`,
  `docs/checklist.md`, `browser-extension/README.md`, build plan note.
- **Test:** full headless sweep + `ruff`.
- **Action:** commit: `Robust Install (3/3) Complete: docs + regression`.

## 4. Invariants
- Loopback-only; no network egress; the extension may reach only `127.0.0.1:$INGEST`.
- One env file is the source of truth for ports; the collector's ingest port and the
  extension's target port are always the same value.
- Unit content is generated by tested Python, never hand-edited by `sed`.
